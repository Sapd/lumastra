# Reviewing episodes in a shared file

Open **Files**, choose the physical file, then **Episodes in this file**. Confirm the named target series and filename before editing. Find episodes by title or episode code and filter by season. The chooser displays up to 50 matches at a time. Search and filtering leave selected episodes in their explicit playback order, including reversed, nonadjacent and cross-season selections.

Read the evidence beside each cut. Saved manual cuts and saved chapter-derived cuts are distinguished from runtime estimates, equal splits and boundaries whose source was not recorded. An estimate is not content verification. Adding or removing an episode clears draft cuts; enter the cuts from the content, choose saved chapter markers, or deliberately choose **Even split** and review that estimate before saving. Moving an episode preserves the existing windows and changes which episode plays in each window.

An empty chapter list means the library has no saved chapter records for this file. Embedded chapters may still exist. **Refresh chapters for linked item** starts the existing chapter refresh for the named playback item and all its file versions. Open its exact run or use **Check run and reload chapters**. A failed or unverifiable run preserves the draft. A successful result reloads saved chapter records for the selected file without replacing selected episodes or edited cuts. Chapter markers still require content review before use as episode boundaries. An unlinked file has no playback item for this refresh action; review the content before assigning episodes.

**Save links** writes only the reviewed episode order and windows through the existing manual mapping workflow. The returned saved mapping is displayed with a retained result message. **Back to automatic** is staged until Save. Closing the editor without saving discards its draft.
