# Provider artwork

`powered-by-audioscrobbler.png` is the unmodified horizontal Powered by AudioScrobbler
button rendered from page 2 of Last.fm’s published brand guide (September 2006):
https://www.catjahnke.com/images/logos/lastfm_brand/lastfm_brandguide%20copy.pdf

Last.fm’s API terms require this button to link to the relevant catalogue page:
https://www.last.fm/api/tos (section 2.7).
