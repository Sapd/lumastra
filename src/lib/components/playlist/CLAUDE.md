# playlist/

Playlist UI components — header, member management, progress tracking, and in-playlist chat.

## Files

| File                            | What                                                | When to read                         |
| ------------------------------- | --------------------------------------------------- | ------------------------------------ |
| `PlaylistHeader.svelte`         | Playlist page header with title, cover, and actions | Modifying playlist header layout     |
| `PlaylistChat.svelte`           | Real-time chat within a playlist                    | Implementing playlist chat feature   |
| `PlaylistMemberPanel.svelte`    | Panel showing playlist members and their roles      | Implementing member management UI    |
| `PlaylistMemberProgress.svelte` | Per-member watch progress display                   | Showing member viewing progress      |
| `PlaylistButton.svelte`         | Add-to-playlist action button                       | Implementing playlist add action     |
| `AddToPlaylistModal.svelte`     | Modal for adding media to a playlist                | Implementing add-to-playlist modal   |
| `AvatarProgressRing.svelte`     | Avatar with progress ring indicator                 | Displaying member progress visually  |
| `ItemWatchers.svelte`           | Avatars of who has watched a playlist item          | Showing item watch status per member |
| `index.ts`                      | Barrel export for playlist components               | Importing playlist components        |
