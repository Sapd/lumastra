# search/

Search UI components — filter bar, results header, empty/loading states, and operator hints.

## Files

| File                        | What                                                   | When to read                              |
| --------------------------- | ------------------------------------------------------ | ----------------------------------------- |
| `SearchHeader.svelte`       | Search page header with result count and sort controls | Modifying search results header           |
| `SearchFilterBar.svelte`    | Media type and genre filter chips bar                  | Implementing search filter controls       |
| `SearchOperatorsBar.svelte` | Search operator hints (field:value syntax tips)        | Implementing advanced search operator UI  |
| `SearchQuickNav.svelte`     | Keyboard-accessible quick navigation overlay           | Implementing quick search/jump navigation |
| `SearchEmptyState.svelte`   | Empty state shown when search returns no results       | Customizing empty search state            |
| `SearchNoResults.svelte`    | No-results with suggestion prompt                      | Customizing no-results messaging          |
| `SearchLoadingState.svelte` | Loading placeholder while search results are fetching  | Customizing search loading state          |
