# scripts/

Automation and maintenance scripts for development, testing, and database operations.

## Files

| File                              | What                                                                                                                                                                                                                | When to read                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `benchmark-queries.ts`            | Database query performance benchmarking utility                                                                                                                                                                     | Running performance tests on database queries                       |
| `build-plugins.ts`                | External plugin ESM bundler (runs during build)                                                                                                                                                                     | Modifying plugin build pipeline                                     |
| `build-proxy-metadata.mjs`           | Rust proxy build fingerprint (runs during app build)                                                                                                                                                                    | Modifying stream proxy build                                        |
| `build-sandbox.ts`                | Worker-thread plugin-isolation bundle (`build/sandbox-entry.js`); runs LAST in build (after vite, which empties `build/`). Has a prod-import guard + `sandbox-stubs/` aliasing                                      | Modifying plugin worker isolation or its bundle                     |
| `cleanup-image-cache.ts`          | Image cache disk space cleanup script                                                                                                                                                                               | Managing image cache storage limits                                 |
| `gen-jellyfin-route-patterns.mjs` | Regenerates `src/lib/routing/jellyfin-route-patterns.ts`, the `/j` route table the reroute hook matches case-insensitively (a test fails when it is stale)                                                          | Adding, renaming or removing a `/j` route                           |
| `increment-sw-version.js`         | Service worker version auto-incrementer                                                                                                                                                                             | Forcing browser cache invalidation after deployment                 |
| `check-vitest-json.mjs`           | Guards a vitest JSON report (missing file / zero collected tests = build failure) and prints the failing files, TEST NAMES and first failure line to `$GITHUB_STEP_SUMMARY`; exits 0 on merely-failing tests        | Finding which integration tests fail and why; CI test-guard changes |
| `check-playwright-json.mjs`       | Reduces a Playwright JSON report to the GREEN spec files (the `e2e-ratchet` candidate list) and the failing ones with reasons, into `$GITHUB_STEP_SUMMARY`; exits 0 on failing specs, 1 only if the suite never ran | Building/growing the e2e ratchet; reading an e2e run's outcome      |
| `migration-status.ts`             | Database migration status verification tool                                                                                                                                                                         | Checking which migrations have been applied                         |
| `quiet-test-postgres.mjs`         | Quietens the CI test Postgres (`log_min_error_statement=panic`, no checkpoint/autovacuum chatter) so the job log tail shows tests, not ~35k chars of expected-error SQL                                             | CI integration log is unreadable; changing test DB logging          |
| `run-tests-batched.sh`            | Batched test execution wrapper for CI                                                                                                                                                                               | Running tests in memory-constrained CI environments                 |
| `dev-worker.mjs`                  | Development launcher for the lean task host and supervised watcher                                                                                                                                                   | Running source development with background jobs                    |
| `security-audit.ts`               | Security vulnerability scanning utility                                                                                                                                                                             | Auditing routes for IDOR vulnerabilities                            |
| `startup-migration.ts`            | Application startup migration runner                                                                                                                                                                                | Understanding automatic migration execution on app start            |
| `verify-schema-sync.ts`           | Zod schema synchronization verification tool                                                                                                                                                                        | Validating Zod schemas match database and API contracts             |

## Subdirectories

| Directory                        | What                                                                    | When to read                                   |
| -------------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------- |
| `eslint-plugin-callback-safety/` | Custom ESLint plugin enforcing callback type safety (see its README.md) | Writing or debugging callback validation rules |
| `openapi/`                       | OpenAPI specification generation scripts                                | Generating or updating API documentation       |
| `test/`                          | Test utilities (synthetic media file generation)                        | Setting up E2E test fixtures                   |
