# Route sweep — running it

Surface: `inventory.generated.json`, regenerated by
`node scripts/route-sweep/gen-inventory.mjs` and drift-checked with `--check`.
The companion `matrix.generated.md` summarizes the same shipped routes.

The sweep targets an already-running remote instance. It never opens a database
connection, and it starts no dev server.

## Why every value below is configuration

Each of these, if guessed wrong, produces a sweep that reports green while testing
nothing:

- **Header names.** The app reads whatever `USERHEADER` / `GROUPHEADER` the
  deployment sets (CI uses `X-Forwarded-*`; an authentik edge typically uses
  `x-authentik-username` / `X-authentik-groups`). Sending the wrong pair
  returns **HTTP 200 with a small anonymous page** instead of the much larger
  authenticated one. The status code does not move, so only the body
  size tells you.
- **The admin group.** `ADMIN_GROUPS` is whatever the deployment configured.
  The dangerous direction is silent: a "non-admin" principal carrying an admin
  group is served as a full admin, and every Tier C assertion passes while
  proving nothing.
- **The base URL.** No default. The config refuses to start without
  `SWEEP_BASE_URL`, so a sweep can never quietly point at localhost.

## Pointing it at an instance

Forward auth (the instance has `FORWARD_AUTH_ENABLED=true` and trusts the peer you connect from via `TRUSTED_PROXY_IPS`):

```bash
export SWEEP_BASE_URL="http://127.0.0.1:3000"
export SWEEP_IDENTITY_MODE=forward-auth
export SWEEP_USER_HEADER=X-Forwarded-User
export SWEEP_GROUP_HEADER=X-Forwarded-Groups
export SWEEP_ADMIN_GROUP=admins
export SWEEP_ADMIN_USERNAME=alice
export SWEEP_ADMIN_GROUPS=admins
export SWEEP_NON_ADMIN_USERNAME=sweepuser
export SWEEP_NON_ADMIN_GROUPS=users
export SWEEP_BUILD=full
```

Forward auth provisions `sweepuser` on first request, so the non-admin principal
needs no seeding. A request from an untrusted peer (for example a curl from inside
the container) gets the anonymous page.

Admin can be conferred by **group membership** (`ADMIN_GROUPS`) as well as the
`is_admin` column. A negative test that treats `is_admin = false` as "non-admin"
tests the wrong thing when the user's groups include an admin group, so give the
non-admin principal groups that are not in `ADMIN_GROUPS`.

Confirm the target before trusting a run. Compare body sizes, because the status
code is 200 either way:

```bash
curl -s -o /dev/null -w '%{http_code} %{size_download}\n' \
  -H "X-Forwarded-User: alice" -H "X-Forwarded-Groups: admins" \
  "$SWEEP_BASE_URL/"
```

A small body (a few KB) is the anonymous page, and every admin result after it is
meaningless.

### Built-in accounts

`SWEEP_IDENTITY_MODE=native-session`, `SWEEP_BUILD=public`, plus
`SWEEP_ADMIN_PASSWORD` / `SWEEP_NON_ADMIN_PASSWORD`. The header variables are
unused.

## Running

```bash
npx playwright test --config=playwright.route-sweep.config.ts
PLAYWRIGHT_JSON_REPORT=sweep.json npx playwright test --config=playwright.route-sweep.config.ts
```

The HTML report is ~16 MB and unreadable outside a browser; the JSON one is how
results get read back.

## Before believing a green run

A sweep that has never failed is not known to work, and a route that cannot be
tested is a BLOCKED row, never a `test.skip()`.

### The self-test (run it when a tier first goes green)

Point the sweep at a server that authorises everything and confirm it goes red:

```bash
node -e "require('node:http').createServer((q,s)=>{s.writeHead(200,{'content-type':'application/json'});s.end('{\"ok\":true,\"items\":[],\"page\":{\"total\":0}}')}).listen(55999,'127.0.0.1')" &
SWEEP_BASE_URL=http://127.0.0.1:55999 npx playwright test --config=playwright.route-sweep.config.ts --project=api tier-c-authz
```

Against the permissive server a few hundred assertions must fail: those are the
ones that change their answer when authorization disappears. The ones that still
pass are the ones that should: count assertions make no request, the `observes` group fails only
on a 5xx by design, and operations declaring no security are not required to
deny.

Do this for a tier whenever it first reports all-green. Every vacuous group
found in this build — 149 v1 assertions that were true for every principal
including a full admin — looked exactly like a healthy green until something
was varied and the answer did not move.
